# Практио

Сервис для поиска и сопровождения производственной практики. Студенты заполняют портфолио, откликаются на практики и ведут дневник. Организации публикуют предложения, рассматривают отклики и оставляют отзывы. Координаторы учебных заведений управляют группами, согласуют практики и проверяют дневники.

## Локальный запуск

Требуется Node.js 24.16 или новее.

```powershell
npm install
npm run build
.\start-local.ps1
```

Адрес: http://localhost:3080. После изменения серверного кода выполните `.\start-local.ps1 -Restart`. После изменения интерфейса пересоберите его и обновите страницу.

Новая база создаётся пустой. Аккаунты регистрируются через форму входа, практики и группы создают пользователи. Примеры организаций, студентов, откликов и документов автоматически не добавляются. Справочники направлений и форматов хранятся в `shared/catalog.json` и используются сервером и интерфейсом совместно.

База и загруженные файлы хранятся в `data/`. Для резервного копирования остановите сервер и сохраните папку целиком. При очистке прежней базы проверенная копия была сохранена в `.local/backups/`; эти файлы не входят в сборку и Git.

Для разработки: `npm run dev:api` и `npm run dev` в отдельных терминалах. Логи локального сервера находятся в `.local/`.

## Основные сценарии

- Студент: профиль, навыки, файлы и ссылки портфолио, проекты GitHub, поиск практики, избранное и отклики.
- Организация: профиль, заполнение сведений по ИНН, публикация практик, рассмотрение откликов, завершение практики и отзыв.
- Координатор: учебные группы, коды приглашения, распределение студентов, согласование практик и проверка дневников.
- Дневник: дата, задачи, часы и результаты; отправка куратору, возврат на доработку и принятие. Согласование практики требуется для отправки и проверки записей.
- Документы: выгрузка дневника и итогового отчёта; отчёт доступен после завершения практики и принятия всех записей. Загруженный документ можно распечатать. Форма сверяется с требованиями учебного заведения.

Профиль и портфолио студента доступны организациям, которым он отправил отклик, и координатору его учебной группы. Доступ к файлам и решениям проверяется на сервере.

## Подключение поиска по ИНН

1. Получите API-ключ в [личном кабинете DaData](https://dadata.ru/profile/#info).
2. Скопируйте `.env.example` в `.env` и заполните `DADATA_API_KEY`.
3. Перезапустите сервер.

Ключ используется только сервером и не попадает в клиентскую сборку. Запрашиваются только ИНН, название, город и отрасль. Перед применением пользователь проверяет сведения, затем сохраняет профиль. Если поиск недоступен, поля можно заполнить вручную. Это автозаполнение сведений, а не проверка полномочий представителя организации.

## GitHub

Студент указывает имя пользователя или ссылку на профиль, выбирает до пяти открытых проектов и сохраняет выбор. Записываются название, описание, основной язык, ссылка, ID и признак копии проекта. Организация видит их в отклике, координатор — в карточке студента. Приватные проекты не запрашиваются, навыки автоматически не назначаются.

Ключ для чтения публичных данных не нужен. Запросы к GitHub кэшируются; ошибки и лимиты обрабатываются сервером. Ссылка не подтверждает владение аккаунтом. Для обновления сохранённого портфолио нужно загрузить и сохранить новый выбор.

## Проверки и состав сборки

`npm run build` проверяет TypeScript и собирает интерфейс. `npm test` запускает изолированные временные базы и проверяет регистрацию, роли, отклики, файлы, группы, согласование, дневники, выгрузки и интеграции. Отдельный сценарий проверяет пустой запуск обычного сервера и сохранение зарегистрированных аккаунтов после перезапуска.

Данные и подмены внешних ответов для автоматических тестов находятся только в `tests/fixtures/`. Их запуск разрешён исключительно с отдельной временной базой. Рабочее приложение их не импортирует. В пакет входят `dist/`, `server/`, `shared/`, конфигурационный пример и инструкция; тесты, локальные данные, ключи и архивы исключены.

Интерфейс использует локальный Manrope. Лицензия находится в `public/fonts/Manrope-OFL.txt` и включается в сборку. Размеры текста, межстрочные интервалы и отступы заданы в `src/typography.css`. Цветовая схема и форма карточек сохранены.

## Размещение

Сейчас сервер слушает локальный адрес. Публичное размещение и инфраструктура релиза выполняются отдельно: домен и HTTPS, почта для восстановления доступа, подтверждение организаций и учебных заведений, резервное копирование и политика обработки персональных данных. Координатор пока управляет одним учебным заведением, а группа описывает один период практики. Сформированные документы не содержат электронной подписи.
